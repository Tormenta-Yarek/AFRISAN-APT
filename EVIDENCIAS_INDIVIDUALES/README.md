# EVIDENCIAS INDIVIDUALES

Esta carpeta contiene las evidencias individuales de cada integrante del proyecto AFRISAN correspondientes a la Fase 1 del Proyecto APT.

## Documentos requeridos por integrante

- 1.1 Autoevaluación de competencias
- 1.2 Diario de reflexión
- 1.3 Autoevaluación individual

## Formato de nombres

Los archivos deben utilizar el siguiente formato:

APELLIDO_NOMBRE_1.1_AUTOEVALUACION_COMPETENCIAS

APELLIDO_NOMBRE_1.2_DIARIO_REFLEXION

APELLIDO_NOMBRE_1.3_AUTOEVALUACION

Los nombres deben escribirse en MAYÚSCULAS y sin tildes.
