## Formato de nombres

Los archivos deben utilizar el siguiente formato:

`APELLIDO_NOMBRE_1.1_AUTOEVALUACION_COMPETENCIAS`

`APELLIDO_NOMBRE_1.2_DIARIO_REFLEXION`

`APELLIDO_NOMBRE_1.3_AUTOEVALUACION`

Los nombres de archivo deben escribirse en MAYÚSCULAS y sin tildes.
