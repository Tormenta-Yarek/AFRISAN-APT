# DOCUMENTACIÓN HISTÓRICA - AFRISAN

Esta carpeta contiene versiones anteriores de la documentación del proyecto AFRISAN.

Los archivos se conservan con fines de trazabilidad académica y permiten registrar la evolución del proyecto desde sus primeras etapas hasta la documentación vigente.

## Importante

Los documentos almacenados en esta carpeta pueden contener:

- Integrantes que participaron en etapas anteriores del proyecto.
- Versiones previas de requisitos y alcance.
- Estructuras, diagramas o decisiones posteriormente actualizadas.
- Información que fue corregida o reemplazada durante el desarrollo del proyecto.

Por este motivo, estos documentos no deben considerarse como la versión vigente del proyecto.
