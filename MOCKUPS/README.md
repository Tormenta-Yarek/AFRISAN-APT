# MOCKUPS DEL SISTEMA

Esta carpeta contiene los mockups iniciales del proyecto AFRISAN desarrollados durante la Fase 1 del Proyecto APT.

## Objetivo

Los mockups permiten representar visualmente la propuesta inicial de la interfaz del sistema antes de comenzar su desarrollo.

Estos diseños sirven para:

- Visualizar la estructura de las principales pantallas.
- Definir la distribución de la información.
- Representar el flujo de navegación del usuario.
- Validar inicialmente la propuesta de solución.
- Servir como referencia para las etapas posteriores de desarrollo.

## Contenido

En esta carpeta se incluirán:

- Mockup inicial del sistema.
- Pantallas principales.
- Flujo de navegación.
- Versiones actualizadas de los diseños, si corresponde.

## Herramienta utilizada

Los mockups pueden ser desarrollados utilizando herramientas como Figma, Canva u otra plataforma de diseño de interfaces.
